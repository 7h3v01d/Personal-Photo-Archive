# Phase 8.0 — Chronology Timeline Foundation

Phase 8 starts with a read-only projection over the accepted Phase-6/7 truth model.
It does not create dates or alter archive evidence.

## Placement lanes

1. **Placed** — fresh confirmed reconstruction, or current TRUSTED/PROBABLY_VALID reconciled chronology.
2. **Ranges** — fresh confirmed reconstruction whose evidence only supports a date range. The range is preserved.
3. **Tentative** — fresh Phase-7 proposal. Visible for context, never presented as authoritative.
4. **Unplaced** — stale decisions or chronology that remains QUESTIONABLE / LIKELY_WRONG / UNKNOWN without a safe replacement.

A rejected reconstruction does not invalidate an independently reliable recorded date. A stale confirmed reconstruction never places a photo.

The desktop Timeline is built off-thread and exposes year/month grouping plus direct photo preview. The same projection is available as `ppa timeline <library_id>` and versioned JSON (`ppa-timeline/1`).
